🎉 Animated Thank You Page

A visually appealing Animated Thank You Page built using HTML5 and CSS3. This project features smooth animations, modern styling, and a responsive layout to create an engaging experience for users after completing an action such as a form submission, registration, or purchase.

✨ Features
Smooth CSS animations and transitions
Attractive thank you message design
Responsive layout for all screen sizes
Clean and modern user interface
Lightweight and fast-loading page
Built entirely with HTML and CSS

🚀 Technologies Used
HTML5
CSS3

📚 What I Learned
Creating animations with CSS keyframes
Using transitions and hover effects
Building responsive page layouts
Improving UI/UX design skills
Structuring clean and maintainable front-end code

This project was created to enhance my front-end development skills by designing an animated and visually engaging thank you page using only HTML and CSS.
